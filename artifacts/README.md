# Evaluation artifacts

Keep current, documented evidence in `evaluation/`, grouped by workstream.
Commerce benchmark contracts live in `../data/evaluation/`; the status page in
`../docs/README.md` links to the latest verified runs. OCR reports and fixtures
remain under `evaluation/ocr/`.

Unreferenced outputs from earlier iterations are preserved in
the worktree only when still useful for the active Commerce/OCR work. Remove
superseded run outputs instead of keeping a second history tree; the benchmark
inputs and current verified reports are the reproducible evidence.

Agent and grounded-QA evaluation outputs belong under `evaluation/agents/`.
Do not treat legacy-corpus results as evidence for the active Commerce workflow.
