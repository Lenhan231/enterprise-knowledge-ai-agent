# QuocAn agent and generation artifacts

This branch retains QuocAn's agent, SQL/report/router and answer-generation
evaluation results, together with required datasets and provenance. OCR,
document-processing, fine-tuning, embedding, retrieval/reranker and Huy held-out
evaluation artifacts are excluded from this branch's current tree.

Teammate artifacts remain available on
[main](https://github.com/Lenhan231/enterprise-knowledge-ai-agent/tree/main/artifacts).
No shared artifacts are deleted from main by this branch cleanup.

The corrected [historical Knowledge baseline versus integrated v3 comparison](https://github.com/Lenhan231/enterprise-knowledge-ai-agent/blob/main/artifacts/evaluation/knowledge-baseline-30-2026-11-12/COMPARISON.md)
is published on main with frozen inputs, raw answers/scores and verified runtime
provenance. The invalid earlier comparison is not included.
