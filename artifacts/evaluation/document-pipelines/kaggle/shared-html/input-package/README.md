# Vietnamese Enterprise Document Pipeline Inputs

Private inference-only input set for the shared HTML benchmark. It contains 51 owner-reviewed page images grouped by source document.

- `shared-html-reviewed-pages.jsonl`: page IDs, relative image paths, and image hashes.
- `images/<document-id>/pNNNN.png`: page images for inference.

Scoring references and labels stay local in the repository and are not included here.
