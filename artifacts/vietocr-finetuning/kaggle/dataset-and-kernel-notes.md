# Enterprise printed OCR fine-tuning data

The two Kaggle notebooks train VietOCR and Tesseract on printed Vietnamese and English line crops. Both kernel metadata files reference the private Kaggle dataset. The expected input contains `dataset-info.json`, train/validation/test annotations and manifests, plus the corresponding image files. Each source PDF must remain within a single split.

The private dataset, source documents, and labels are not included in this archive.
